# Lift

Simon’s personal strength-workout PWA.

- Live app: <https://simoncjwilson-tech.github.io/Workout/>
- Current version: **Lift v1.3 — Norse Fitness**
- Sessions save locally and back up to a private GitHub Gist.
- Odin’s scheduled fitness sync imports new sessions into the file-native Fitness log used by Norse Health.
- Lift does not write to Apple Health; any future HealthKit/Shortcut bridge is a separate opt-in feature.
